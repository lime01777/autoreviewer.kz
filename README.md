# autoreviewer — Каталог автосалонов и автомагазинов

Профессиональная платформа для поиска и оценки автосалонов с системой отзывов, новостями и рекламными возможностями.

## Основные возможности
- **Каталог организаций**: Удобный поиск и фильтрация по категориям и городам.
- **Система отзывов**: Возможность оставлять отзывы без регистрации с пре-модерацией.
- **Личный кабинет**: Избранное, история отзывов и управление профилем.
- **Новости**: Актуальные события автомобильного мира.
- **Рекламная система**: Управление баннерами в различных позициях через админку.
- **Админ-панель**: Полный контроль над контентом на базе Filament v5.

## Инструкция по деплою (на обычный PHP-хостинг)

### 1. Подготовка файлов
- Загрузите все файлы проекта в корневую директорию вашего хостинга (обычно на один уровень выше `public_html` или непосредственно в корень, если хостинг позволяет менять Document Root).
- **Важно**: Основной точкой входа должна быть папка `public`. Настройте ваш веб-сервер (Apache/Nginx) так, чтобы `Document Root` смотрел в `/path/to/project/public`.

### 2. Настройка окружения (.env)
- Создайте файл `.env` на основе `.env.example`.
- Обязательно установите:
  ```env
  APP_ENV=production
  APP_DEBUG=false
  APP_URL=https://autoreviewer.kz
  ```
- Сгенерируйте ключ (если не сделали локально): `php artisan key:generate`.

### 3. База данных (MySQL)
- Создайте базу данных через панель хостинга.
- Впишите данные в `.env`:
  ```env
  DB_CONNECTION=mysql
  DB_HOST=127.0.0.1
  DB_PORT=3306
  DB_DATABASE=имя_бд
  DB_USERNAME=пользователь
  DB_PASSWORD=пароль
  ```

### 4. Выполнение команд
Через SSH в корне проекта выполните:
```bash
# Установка зависимостей без dev-пакетов
composer install --optimize-autoloader --no-dev

# Запуск миграций (и сидеров, если нужно наполнить базу)
php artisan migrate --force
# Для первого запуска с тестовыми данными:
php artisan migrate:fresh --seed --force

# Очистка и кэширование настроек
php artisan config:cache
php artisan route:cache
php artisan view:cache
```

### 5. Настройка хранилища (storage:link)
- Выполните: `php artisan storage:link`.
- Если на хостинге нет SSH, создайте PHP-файл в папке `public` с кодом `<?php symlink('/path/to/storage/app/public', '/path/to/public/storage'); ?>` и запустите его один раз через браузер.

### 6. Права доступа
Убедитесь, что веб-сервер имеет права на запись в следующие папки:
- `storage` (рекурсивно)
- `bootstrap/cache`
Обычно это `chmod -R 775 storage bootstrap/cache`.

## Инструкция для администратора

### 7. Создание администратора
Если вы не запускали сидеры, создайте админа через консоль:
```bash
php artisan tinker
>>> $user = new \App\Models\User();
>>> $user->name = 'Admin';
>>> $user->email = 'admin@yourdomain.com';
>>> $user->password = Hash::make('yourpassword');
>>> $user->role = 'admin';
>>> $user->save();
```

### 8. Вход в админку
- Перейдите по адресу: `https://autoreviewer.kz/admin`.
- Используйте email и пароль, созданные выше.
- Доступ обычных пользователей в этот раздел **запрещен**.

### 9. Как добавить первый автосалон
1. В боковом меню выберите **"Автосалоны"**.
2. Нажмите **"Создать"**.
3. Заполните основные данные: название, город, адрес.
4. Вкладка **"Категории"**: выберите подходящие (предварительно создав их в разделе "Категории").
5. Вкладка **"Медиа"**: загрузите логотип и обложку (оптимально до 2МБ).
6. Установите статус **"Published"** для отображения на сайте.

### 10. Модерация отзывов
1. Все новые отзывы попадают в раздел **"Отзывы"** со статусом `pending`.
2. На публичной части сайта они **не видны** до одобрения.
3. Администратор заходит в отзыв, проверяет текст на спам и мат.
4. Меняет статус на **"Approved"** — отзыв появляется на странице автосалона и влияет на его рейтинг.

## SEO и поисковое продвижение
- **Sitemap**: Карта сайта доступна по адресу `/sitemap.xml`. Генерируется автоматически.
- **Robots**: Файл `/robots.txt` настроен и указывает путь к sitemap.
- **Schema.org**: На страницах автосалонов встроена микроразметка `LocalBusiness` и `AggregateRating`.
- **Meta**: Все страницы поддерживают кастомные Title и Description.
